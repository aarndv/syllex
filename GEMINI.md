# Gemini Agent Rules & Guidelines

- **Git Commit & Push Directive**: ALWAYS stage, commit, and push all git changes whenever code or file modifications are made in the repository, unless explicitly instructed otherwise by the user.
- **Icon Directive**: NEVER use emojis for UI icons, buttons, labels, badges, or tree elements. Use clean SVG icons, CSS glyphs, or explicit text labels.
- **Reference**: See `AGENTS.md` for full workspace rules, architectural invariants, security guidelines, and definition of done.
